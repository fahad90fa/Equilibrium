# Gallery — drop your media here

Any file you place in this folder appears automatically in the
"Inside the Arena" gallery section (dev server picks it up instantly;
for production run `npm run build` again).

Supported: `.jpg` `.jpeg` `.png` `.webp` `.avif` `.gif` `.mp4` `.webm`

- The filename becomes the caption: `squad-row-night.jpg` → "SQUAD ROW NIGHT"
- Files are ordered alphabetically — prefix with `01-`, `02-`… to control order
- Videos autoplay muted in the grid and get player controls in the viewer
- Keep videos short (5–15s clips) and under ~10 MB for fast loading

Great sources: your Instagram posts/reels (@equilibriumgamingpk).
